プライバシーポリシー（Privacy Policy）

最終更新日：2026年11月24日

ashot-news（以下「運営者」）は、ニュース動画投稿ツール（以下「本ツール」）での情報の取り扱いを、次のとおり定めます。

1. 取得する情報

本ツールは、運営者自身の TikTok アカウントおよび YouTube チャンネルに動画を投稿するため、運営者が許可した範囲で次の情報を利用します。

  • TikTok：アカウントの基本情報（user.info.basic）、動画の下書き送信・投稿の権限（video.upload、video.publish）
  • YouTube：動画のアップロードの権限

運営者以外の利用者の個人情報は、取得しません。

2. 利用目的

取得した情報は、運営者のアカウントに動画を投稿するためだけに使います。

3. 保管

ログインに必要な認証情報（アクセストークン）は、運営者のパソコン内にのみ保存し、外部のサーバーには保存しません。

4. 第三者への提供

取得した情報を、第三者に提供・販売することはありません。ただし、動画の投稿のために TikTok および YouTube（Google）の API に必要な情報を送信します。

5. 情報の削除

TikTok・YouTube のアカウント設定から本ツールへの許可を取り消すことで、いつでも情報の利用を止められます。運営者のパソコン内の認証情報も削除します。

6. 変更

本ポリシーは、必要に応じて変更することがあります。変更後の内容は、このページに掲載した時点から有効になります。

7. お問い合わせ

https://github.com/ashot-news

English summary: This tool is used only by its operator (ashot-news) to post videos to the operator's own TikTok account and YouTube channel. It uses only the permissions the operator grants (TikTok: user.info.basic, video.upload, video.publish; YouTube: video upload). Access tokens are stored only on the operator's own computer and are never sold or shared with third parties, except for the data sent to the TikTok and YouTube APIs to post videos. No personal data of other users is collected.
